# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the ESLint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and [`typescript-eslint`](https://typescript-eslint.io) in your project.

📌 Smart Leave Management System
📖 Project Overview

The Smart Leave Management System is a web application built using React, Redux Toolkit, Redux Thunk, and Tailwind CSS.
It allows users to apply for leave, manage leave records, and filter leave requests efficiently.

This project demonstrates state management, asynchronous operations, and modern UI design, making it suitable for academic submission and beginner-level industry practice.

🚀 Features
📝 Apply Leave

Users can apply for different types of leave:

Sick Leave

Casual Leave

Emergency Leave

Vacation Leave

Half-Day Leave

Stores:

Employee Name

Leave Type

Start Date

End Date

Reason

Status

📋 View Leave Records

Displays leave requests in a clean card layout

Shows:

Name

Leave Type

Duration

Reason

Status

✏️ Update Leave Status

Approve leave

Reject leave

❌ Delete Leave

Remove any leave record instantly

🔍 Search & Filter

Search by employee name

Filter by leave type (Sick, Vacation, etc.)

⚡ Real-Time Updates

UI updates instantly using Redux state

No page refresh required

🛠️ Tech Stack

Frontend: React.js

State Management: Redux Toolkit

Middleware: Redux Thunk

Styling: Tailwind CSS

Backend (Mock API): JSON Server
